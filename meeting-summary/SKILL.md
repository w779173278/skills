# Meeting Summary

从原始笔记或转录生成结构化会议纪要。

## 会议类型

| 类型 | 聚焦 |
|------|------|
| **standup** | 昨天/今天/阻碍 |
| **review** | 成果/反馈/改进 |
| **planning** | 目标/任务/估算 |
| **brainstorm** | 想法/评估/决策 |
| **retrospective** | 做得好/待改进/行动项 |
| **general** | 议题/讨论/决策/行动 |

## 输出格式

使用 [[meeting]] 模板，`meeting_type` 字段填对应类型（见上表）。

## 处理规则

1. **提取决策** — 识别"决定了"/"确认"/"同意"等信号词
2. **提取行动项** — 识别"负责"/"跟进"/"TODO"/"下次"等信号词
3. **去冗余** — 删除闲聊、重复讨论、无结论的发散
4. **归类** — 按议题分组，不要按时间顺序罗列
5. **补全** — 行动项必须有负责人和截止日期，缺失则标注 `[待确认]`

## 输入格式

支持：
- 纯文本笔记
- 会议转录（含发言人标记）
- 聊天记录
- 录音转文字
