# 监控与可观测性规格

## 1. 核心 Metrics 指标
[列出核心监控指标，包含指标类型、维度/Label 及建议告警阀值]

| 指标名称 (Metric Name) | 类型 | 标签/维度 (Labels) | 描述说明 | 告警红线建议 |
| :--- | :--- | :--- | :--- | :--- |
| `http_requests_total` | Counter | `uri`, `status` | HTTP 接口总请求调用次数。 | - |
| `http_request_latency_ms` | Histogram | `uri` | HTTP 请求调用耗时分布（毫秒）。 | p99 耗时 > 1000ms 则告警 |
| `system_cpu_usage` | Gauge | `node_ip` | 节点的系统 CPU 使用率。 | > 85% 则告警 |

## 2. Prometheus 告警规则配置 (YAML)
```yaml
groups:
  - name: [模块告警规则组名]
    rules:
      - alert: HttpRequestLatencyTooHigh
        expr: http_request_latency_ms{quantile="0.99"} > 1000
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "URI {{ $labels.uri }} p99 latency is too high"
```
