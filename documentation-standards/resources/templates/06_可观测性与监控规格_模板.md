# 监控与可观测性规格

## 1. 核心 Metrics 指标
[列出核心监控指标，包含指标类型、维度/Label 及建议告警阀值]

| 指标名称 (Metric Name) | 类型 | 标签/维度 (Labels) | 描述说明 | 告警红线建议 |
| :--- | :--- | :--- | :--- | :--- |
| `rocketmq_consumer_lag` | Gauge | `topic`, `group` | 消费者分组未消费的积压消息总数。 | > 10,000 条持续 5 分钟则告警 |
| `rocketmq_send_latency` | Histogram | `topic`, `status` | 生产者发送消息的耗时分布。 | p99 耗时 > 500ms 则告警 |
| `rocketmq_broker_cpu` | Gauge | `broker` | Broker 节点的 CPU 使用率。 | > 80% 则告警 |

## 2. Prometheus 告警规则配置 (YAML)
```yaml
groups:
  - name: [模块告警规则组名]
    rules:
      - alert: RocketmqConsumerLagTooHigh
        expr: rocketmq_consumer_lag > 10000
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "Consumer Group {{ $labels.group }} on Topic {{ $labels.topic }} lag is too high"
```

## 3. 常见运维诊断命令
列出常用排查与诊断指令（如 CLI 工具）：
*   **查看路由信息**：
    ```bash
    sh mqadmin topicRoute -n localhost:9876 -t MyTopic
    ```
*   **查看消费进度**：
    ```bash
    sh mqadmin consumerProgress -n localhost:9876 -g MyConsumerGroup
    ```
