# 快速开始：服务本地单机部署与验证

## 1. 环境准备
- JDK 17 或更高版本
- Maven 3.6.x 或更高版本
- 操作系统限制：Linux/Unix/macOS/Windows

## 2. 步骤一：编译与打包
从源码包克隆或下载解压：
```bash
git clone [代码仓克隆地址]
cd [代码目录]
mvn clean package -DskipTests
```

## 3. 步骤二：启动核心服务
启动编译打包后的 Jar 可执行包：
```bash
# 启动配置与注册服务组件
nohup java -jar target/bootstrap-service.jar --spring.profiles.active=dev &

# 验证服务启动日志是否正常
tail -f ~/logs/applogs/startup.log
```

## 4. 步骤三：客户端发送与接收验证
使用 curl 调试接口验证服务是否就绪：
```bash
# 发起服务自检探针接口
curl http://localhost:8080/actuator/health

# 应答结果应为：{"status":"UP"}
```
