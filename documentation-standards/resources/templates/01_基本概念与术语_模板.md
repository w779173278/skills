# 基本概念与术语

本文介绍 [模块名称] 的基本概念与核心术语，以便您在深入技术细节前建立整体认知。

## 核心术语表 (Glossary)
| 术语名称 (EN/CN) | 一句话本源定位/定义描述 | 详细领域模型链接 (若有) |
| :--- | :--- | :--- |
| **主题 (Topic)** | 消息传输和存储的顶层容器，标识一类业务逻辑的消息。 | [查看详细定义](./领域模型/02_主题实体定义.md) |
| **消息队列 (MessageQueue)** | 消息存储和传输的实际物理容器，也是消息的最小存储单元。 | [查看详细定义](./领域模型/03_队列实体定义.md) |
| **生产者 (Producer)** | 系统中用来构建并传输消息到服务端的运行实体。 | [查看详细定义](./领域模型/04_生产者实体定义.md) |
| **消费者 (Consumer)** | 用来接收并处理消息的运行实体。 | [查看详细定义](./领域模型/05_消费者实体定义.md) |
| **订阅关系 (Subscription)** | 消费者获取消息、处理消息的过滤规则和进度状态配置。 | [查看详细定义](./领域模型/06_订阅实体定义.md) |
